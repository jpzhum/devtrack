# Como contribuir

O DevTrack usa contribuições pequenas e revisáveis, vinculadas ao planejamento do projeto.

## Antes de começar

1. Escolha ou confirme uma Issue.
2. Alinhe o escopo e os critérios de aceite.
3. Atualize sua branch `develop` local.
4. Crie uma branch de tarefa a partir de `develop`.

Para implementações, use `feature/<descricao-curta>`. Para documentação, use `docs/<descricao-curta>`.

## Durante a tarefa

- mantenha as alterações dentro do escopo da Issue;
- faça commits claros e focados;
- não versione dependências instaladas, builds ou dados sensíveis;
- execute as validações aplicáveis e registre o resultado no Pull Request;
- preserve a autoria de quem executou a tarefa.

## Pull Request e revisão

Abra o Pull Request para `develop` e preencha o template. A descrição deve informar a Issue relacionada, as mudanças realizadas e a forma de validação. Ajustes solicitados na revisão devem ser feitos na mesma branch.

O merge ocorre somente após revisão. A branch `main` é reservada a versões estáveis promovidas a partir de `develop`.

## Aprendizagem e autoria

Cada pessoa responsável por uma tarefa de aprendizagem deve investigar, implementar e conseguir explicar a própria solução. IA e outras ferramentas podem auxiliar pesquisa e revisão, sem substituir esse processo ou produzir automaticamente a resposta da tarefa.
